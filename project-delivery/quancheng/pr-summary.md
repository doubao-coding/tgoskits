# 泉城比赛参赛 PR 清单

## 1. 说明

本文用于汇总本项目参加泉城比赛期间形成的 PR 列表，并说明每个 PR 与赛题三项任务之间的对应关系。三项任务按照“底座 -> 链路 -> 应用”的关系组织：

- 任务一：实时性与隔离底座，支撑混合系统在虚拟化环境中稳定运行。
- 任务二：客户机通信底座，支撑智能侧客户机与控制侧客户机之间可靠通信。
- 任务三：AI 联动应用，基于前两项能力完成推理、控制和状态回传闭环。
